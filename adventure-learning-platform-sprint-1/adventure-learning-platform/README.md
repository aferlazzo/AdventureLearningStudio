# Adventure Learning Platform

This repository contains the first working platform sprint: the **Adventure Library**.

## Run the application

1. Extract the ZIP file.
2. Open `index.html` in Microsoft Edge, Chrome, or Firefox.
3. No installation or web server is required.

## Sprint 1 capabilities

- Create an Adventure
- Open and edit an Adventure
- Delete an Adventure
- Duplicate an Adventure
- Search the library
- Filter by status
- Track Draft, Complete, and Published states
- Store the library in browser local storage
- Export the library as JSON
- Import a previously exported library

## Current limitation

The **Open** button edits the Adventure's library record. Sprint 2 will connect it to the Conversation Engine and begin filling the canonical Adventure object.

## Files

- `index.html` — application shell
- `styles.css` — user interface styling
- `app.js` — Adventure Library behavior
- `ADVENTURE.md` — canonical Adventure specification
- `SPRINT-1.md` — sprint scope and completion criteria
