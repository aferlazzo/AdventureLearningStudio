# Sprint 1 — Adventure Library

## Goal

Create the platform home screen where authors can create, locate, organize, and reopen Adventures.

## Included

- Create
- Open
- Edit
- Delete
- Duplicate
- Search
- Status filtering
- Local persistence
- JSON import and export

## Definition of Done

Sprint 1 is complete when an author can close the browser, reopen the application, and find the saved Adventure Library intact.

## Deferred

- Conversation Engine
- Full Adventure Workspace
- Publishing Center
- Learning Engine
- Accounts
- Cloud synchronization
