# Adventure Learning Studio — Version 1

This is a self-contained browser prototype of the Adventure Learning Studio Situation Builder.

## Run it

1. Extract the ZIP file.
2. Double-click `index.html`.
3. The Studio opens in your browser.

No installation, server, or internet connection is required.

## What Version 1 does

- Creates and manages situations
- Captures anxiety, capability, story, episodes, and skills
- Captures Tony's Tips, warnings, common mistakes, and reassurance
- Shows mission readiness and coaching prompts
- Saves work automatically in browser local storage
- Exports and imports a project as JSON
- Exports individual situations as JSON
- Generates a mission draft as Markdown

## Important

Data is stored in the browser on the computer where you use the Studio. Use **Export Project** regularly to create a backup.

## Version 1 scope

This version proves the authoring workflow. It intentionally does not include accounts, databases, web publishing, PDF generation, AI assistance, or Google Drive integration.
