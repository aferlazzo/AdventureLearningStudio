# Adventure Learning Studio v2.1

## Run it

1. Extract the ZIP file.
2. Open `index.html` in Microsoft Edge, Chrome, or Firefox.
3. No installation or server is required.

## Included in v2.1

- Four visible phases: Discover, Capture, Build, Finish
- Ten guided conversations
- One question at a time
- Explanations and examples
- Reflection and confirmation before continuing
- Back, Save, and Continue controls
- Multiple Adventures
- Automatic browser storage
- Live Adventure summary
- Markdown export
- JSON import and export
- Responsive layout

## Storage

The Studio stores work in the browser's local storage. Export the project as JSON to make a portable backup.
