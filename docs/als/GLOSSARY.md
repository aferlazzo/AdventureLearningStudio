# Adventure Learning Studio
# Glossary

This glossary defines the standard terminology used throughout Adventure Learning Studio.

These definitions should remain consistent across the documentation, user interface, and source code.

---

# Adventure

A complete learning project.

An Adventure contains one or more Missions organized around a common learning objective.

Examples:

- The Practical Car Knowledge Nobody Ever Taught You
- Workplace Safety
- Financial Literacy

---

# Mission

A single learning unit within an Adventure.

Each Mission teaches one practical idea, concept, or skill.

Missions are designed to be completed independently while contributing to the learner's overall progress.

---

# Story

The instructional narrative of a Mission.

The Story explains the learning problem, provides guidance, and leads the learner toward the desired outcome.

---

# Storyboard

The visual plan for a Mission.

The Storyboard defines the sequence of scenes before artwork is created.

---

# Scene

A single step within the Storyboard.

A Scene describes what happens, who is involved, and what should be shown visually.

One Scene may produce one or more comic panels.

---

# Panel

A single visual frame.

Panels may contain comic artwork, diagrams, photographs, or other visual elements that support learning.

---

# Dialogue

Text associated with a Panel.

Dialogue includes:

- Speech
- Thoughts
- Narration
- Captions
- Sound effects

Dialogue remains separate from artwork whenever practical.

---

# Asset

A reusable file used by an Adventure.

Examples include:

- Images
- Icons
- Diagrams
- Audio
- Video
- Documents

Assets are referenced rather than duplicated.

---

# Preview

A generated view of a Mission before publication.

Preview allows authors to review the learner experience without modifying the published product.

---

# Publish

The process of generating the finished learning product from an Adventure.

Publishing transforms authoring content into one or more output formats.

Examples include:

- Website
- PDF
- Print
- Future platforms

---

# Guided Workspace

The primary authoring experience.

The Guided Workspace leads authors through the recommended workflow one step at a time.

---

# Advanced Workspace

An alternative workspace that provides direct access to editing tools for experienced authors.

---

# Learning Outcome

The desired result for the learner after completing a Mission or Adventure.

Examples include:

- Practical knowledge
- Confidence
- Competence
- Better decisions
- Safer behavior
- New skills

The Adventure defines the learning outcome.

---

# Workspace

The area of the Studio where authors create and edit Adventures.

Different workspaces may support different authoring styles while using the same underlying data model.

---

# Learning Product

The published result created from an Adventure.

Examples include:

- Website
- Booklet
- PDF
- Seminar materials

Learners interact with the Learning Product—not the Adventure itself.

---

# Author

A person who creates or maintains an Adventure using Adventure Learning Studio.

---

# Learner

A person who completes Missions within a published Learning Product.

---

# Guiding Principle

Adventure Learning Studio defines **how** learning products are created.

Each Adventure defines **what** is being taught.
