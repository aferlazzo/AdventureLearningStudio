Project: Clarify the Product

Goal: Make every part of the project tell the same story.

Phase 1 — Define the Product (Today)

Deliverable: One document that becomes the source of truth.

We'll write:

Product Vision
Target audience
One-sentence elevator pitch
Vocabulary
Naming standards
Mission standards
What the product is
What the product is not

This becomes the document every future decision refers back to.

Phase 2 — Rename the Product

Replace old terminology everywhere.

Examples:

Adventure	Mission
Confidence (as promise)	Practical Car Knowledge
Guide	Collection of Missions

This affects:

Website

Phase 3 — Rewrite the Introduction

This is probably the biggest change.

Instead of talking about confidence...

...talk about this:

Nobody ever taught you these things.

The introduction should make the reader think

"That's me."

Phase 4 — Audit Every Mission

For every mission ask:

Does this fit the promise?

Questions:

Is this practical?
Would most people say nobody taught them this?
Is it useful?
Is it short?
Is it one skill?

If not...

Rewrite or remove it.

Phase 5 — Audit the Website

Every page should answer:

Why should I care?

We'll simplify:

Home page
Navigation
Landing pages
Mission library
Feedback page
Phase 6 — Simplify the Code

Only after the product is clear.

We'll rename:

classes
folders
variables
comments

to match the new vocabulary.

No behavior changes.

Only clarity.

Phase 7 — Publish Version 2

Now everything matches:

Website
Booklet
Seminar
Documentation
Source code
Rule Going Forward

Every new mission must answer one question:

Would someone honestly say, "Nobody ever taught me this"?

If yes...

It belongs.

If not...

Don't write it.
