# Adventure Learning Studio Architecture

## Purpose

Adventure Learning Studio is a web application for creating confidence-building learning adventures.

The application guides authors through building interactive comic-based learning experiences.

---

## Major Components

- Guided Workspace
- Advanced Workspace
- Comic Builder
- Storyboard
- Asset Manager
- Preview
- Publisher

---

## Application Flow

Author

↓

Guided Authoring

↓

Mission Model

↓

Comic Panels

↓

Preview

↓

Published Adventure
