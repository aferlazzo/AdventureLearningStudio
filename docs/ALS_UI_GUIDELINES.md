# Adventure Learning Studio UI Guidelines

## Principles

- One primary action per screen.
- Avoid clutter.
- Prefer large, clear controls.
- Minimize unnecessary typing.
- Guide instead of overwhelm.
- Support desktop, tablet, and mobile layouts.
- Provide immediate, understandable feedback.
- Reveal advanced tools only when they are needed.
- Keep the learner and learning outcome visible in authoring decisions.

Every screen should answer:

> What should I do next?
