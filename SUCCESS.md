# SUCCESS.md

## Purpose

This document defines what success looks like for Adventure Learning.

Unlike the roadmap, which describes **how** we intend to build the
platform, this document describes **what must be true** when the
platform is successful.

Every significant design decision should move the project closer to
these outcomes.

------------------------------------------------------------------------

# Product Success

Adventure Learning is successful when experts naturally use it to
capture their experience and transform it into Adventures that build
confidence.

The platform should become the preferred way to create, improve, and
publish educational content.

------------------------------------------------------------------------

# Platform Success Criteria

## 1. Experts Start with the Studio

When an expert wants to teach something, their first instinct is to open
Adventure Learning Studio---not a word processor, presentation program,
or comic editor.

## 2. Adventures Become the Source of Truth

Every educational output originates from an Adventure.

Change the Adventure once. Regenerate everything else.

## 3. Publishing Is Automatic

A single Adventure can generate:

-   Driver Confidence Guide mission
-   Comic storyboard
-   Website content
-   PDF
-   Seminar outline

## 4. The Platform Learns

Every completed Adventure improves the platform.

The Learning Engine identifies:

-   repeated concepts
-   missing skills
-   duplicated warnings
-   inconsistent terminology
-   opportunities for reuse
-   gaps in the curriculum

## 5. The Studio Improves Authors

The Studio helps authors think more clearly.

It asks better questions, identifies assumptions, recommends
improvements, and acts like an experienced instructional designer.

## 6. Driver Confidence Guide Is Built from Adventures

The Driver Confidence Guide is the reference implementation for
Adventure Learning.

Every mission is generated from an Adventure.

Updating an Adventure automatically improves future versions of the
Driver Confidence Guide.

## 7. Adventure Learning Extends Beyond Driver Education

The framework should prove useful in domains such as:

-   first aid
-   cooking
-   retirement planning
-   technology for seniors
-   woodworking
-   photography
-   home maintenance

------------------------------------------------------------------------

# Guiding Principles

-   Adventure is the primary asset.
-   Missions are generated, not authored.
-   Simplicity beats complexity.
-   Capture experience before polishing presentation.
-   Complete feedback loops before adding new features.
-   Every Adventure should strengthen the platform.

------------------------------------------------------------------------

# Ultimate Measure of Success

Someone who has never met the original creators can use Adventure
Learning to capture expert knowledge, create effective educational
content, and continuously improve that content through the platform
itself.

Adventure Learning has become a repeatable system for building
confidence through experience.
